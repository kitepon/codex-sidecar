- Date: 2026-08-30
- Publication commit: `74af0c6fade8059e250578dab6f7880466835828`
- Purpose: verify the already-published npm artifacts before restoring the missing GitHub v0.3.11 record

## Method

1. A detached clean worktree was created at the publication commit.
2. The stale 0.3.9 workspace specifiers in that commit's lockfile made
   `corepack pnpm install --frozen-lockfile` fail. This is a reproducibility defect in the commit,
   not an artifact mismatch; 0.3.12 synchronizes the tracked lockfile.
3. Dependencies were reconstructed with pnpm 10.10.0 using the package manifests, all three packages
   were built, and `pnpm pack` rewrote the workspace protocol for registry publication.
4. Each local tarball and its npm 0.3.11 counterpart was extracted. `diff -qr` reported no differing
   or missing file for core, CLI, or MCP.
