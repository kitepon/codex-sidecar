# Node.js 22.13.0 minimum-runtime evidence

- Date: 2026-08-30
- Contract: root, core, CLI, and MCP declare `engines.node = ">=22.13.0"`
- Primary specification: [Node.js SQLite documentation](https://nodejs.org/api/sqlite.html)

`node:sqlite` was introduced in Node 22.5.0, but Node 22 required
`--experimental-sqlite` until 22.13.0. `codex-sidecar-core` imports
`DatabaseSync` unconditionally and never adds that flag, so 22.5.0 is not a
usable product minimum.

## Boundary probe

- Node 22.12.0, no flag: importing `node:sqlite` failed with
  `ERR_UNKNOWN_BUILTIN_MODULE`.
- Node 22.13.0, no flag: `DatabaseSync(":memory:")`, table creation, and close
  succeeded. Node emitted the expected experimental-status warning only.

## Packed-install smoke

The 0.3.12 core, CLI, and MCP packages were built and packed with pnpm 10.10.0,
installed together into an empty npm prefix, and then executed with Node
22.13.0:

- CLI `--version`: `0.3.12`
- `factory-errors --action snapshot`: `status="ok"`, store schema `2`
- MCP initialize: `serverInfo.version="0.3.12"`

This fixes 22.13.0 as the lowest unflagged runtime tested against the actual
distributed package trees.
